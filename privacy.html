Privacy Policy

DarkChannelStudio

Last updated: September 8, 2026

Information Processed

DarkChannelStudio stores TikTok OAuth tokens locally on the user's computer after the user completes TikTok authorization. The application may also process generated video files, captions, metadata, subtitles, publishing status, and local workflow records.

How Information Is Used

TikTok account access is used to identify the connected account, check creator posting options, upload selected videos, and query publishing status through TikTok's APIs.

Local Storage

Access tokens and workflow data are stored locally by the application. DarkChannelStudio does not sell personal information and does not use TikTok data for advertising.

Third-Party Services

When the user chooses to publish to TikTok or YouTube, selected content and metadata are sent to those platforms according to their API requirements and policies.

Contact

For privacy questions about DarkChannelStudio, contact the project owner through the GitHub organization that hosts this website.
